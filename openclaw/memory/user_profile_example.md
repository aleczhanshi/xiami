### 工作风格
- 对产出质量要求高：不要空洞的选项列表，要有明确推荐和理由（"领导都是要对吧"）
- 会直接指出问题不绕弯子，期望快速修正，不要解释为什么错了直接改
- 迭代式工作：先出初版 → 反馈 → 快速改 → 再反馈，循环多轮
- 不喜欢等太久：后台任务跑太慢会催（"都拿了一辈子了"）

### 质量标准
- 价格必须精确数字，不要区间，要标注来源
- 图片必须和内容对应，不能瞎贴
- 数据来源可追溯（博主名+赞数、平台名+查询时间）
- 酒店要实际可订，标注库存和售罄状态

### 视觉偏好
- 以图为主导，文字精简
- 偏好白底/浅色系（"黑底有点看不清楚"）
- 每页内容铺满，不留空白
- 图片要大，占主体面积

### 思维特点
- 善于系统化思考：会主动要求建 skill 库、记 memory、做复盘
- 关注可复用性：希望这次做的事下次还能用
- 会追问工具原理（"注册到哪儿呢"、"有没有 SKILL.md 汇总"）
